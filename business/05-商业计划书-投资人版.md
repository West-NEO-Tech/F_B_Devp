# BizSim — 商业计划书

**数百 Agent 驱动的大规模市场模拟 × 创业验证平台**

---

## Executive Summary

BizSim 是一个基于 **大规模多 Agent 市场模拟** 的创业验证平台。创业者输入产品描述，系统自动生成数十到数百个消费者、企业客户、竞争对手、投资人、供应商、监管方等多角色 Agent，在虚拟市场环境中自由交互、博弈、涌现，在数分钟内完成一场完整的市场推演，生成包含采用曲线、情绪分布、转化漏斗、单位经济学等多维度的商业可行性分析报告。

**核心差异**：

| 维度 | 传统 AI 验证工具 | 固定 Agent 团队（IdeaProof 式） | **BizSim（我们）** |
|------|---------------|--------------------------|-------------------|
| Agent 数量 | 0（单 LLM） | 7-8 个固定角色 | **数十到数百个动态生成** |
| 分析方式 | LLM 问答 | 串行清单分析 | **市场行为模拟涌现** |
| Agent 交互 | 无 | 无 | **自由博弈、口碑传播、竞品反应链** |
| 技术壁垒 | 极低 | 低（prompt chain） | **高（模拟引擎 + 层级化 Agent 协调）** |

**目标市场**：澳洲市场。面向独立开发者、CS 毕业生、创业课堂学生、Vibe Coder 等"产品做得快但不知道怎么验证"的群体。

**商业模式**：按次付费（A$29-49/次）+ Pro 订阅（A$79/月）+ 教育许可 + 培训服务。

## 1. 解决什么问题

### 1.1 痛点

AI 辅助开发（Cursor、Windsurf、Bolt 等）让产品开发从"数月"压缩到"数天"，但商业验证仍然停留在传统速度：

| 传统验证方式 | 成本 | 时间 | 问题 |
|------------|------|------|------|
| 投广告测试 | $500-5,000+ | 2-4 周 | 贵，且只能测试点击率 |
| 用户访谈 | $0-500 | 2-4 周 | 慢，且存在社交偏差 |
| 真实发布 | 机会成本巨大 | 3-6 月 | 如果失败代价极高 |
| 咨询服务 | $2,000-20,000 | 4-8 周 | 贵且建议难以验证 |

**结果**：大量创业者要么跳过验证直接投入（90% 失败率），要么因验证成本过高而放弃好想法。在 Vibe Coding 时代，"做一个 App" 变得容易了，但 "知道该不该做" 没有跟上。

### 1.2 解法

用数百 Agent 的大规模市场模拟替代传统市场试错：

```
输入创业想法
   ↓
自动生成 100-300 个多角色 Agent（消费者/企业客户/竞品/投资人/供应商/监管方/专家/导师）
   ↓
Agent 之间自由交互 30-100 轮（讨论/争论/合作/竞争/口碑传播/竞品反应）
   ↓
涌现出群体行为模式（采用曲线、情绪分布、竞品反应链、转化漏斗）
   ↓
生成可行性报告 + 与任意 Agent 深度对话
```

**核心价值**：在投入真金白银之前，先在数字沙盘里"发布"一次你的产品——看到的不是一个 AI 的建议，而是一个 **虚拟市场的反馈**。

## 2. 产品

### 2.1 产品功能

BizSim 涵盖创业验证全流程的 **14 个功能模块**：

| 模块 | 功能 |
|------|------|
| **Overview 仪表盘** | 项目概览、关键指标、活跃项目统计 |
| **Projects 管理** | 多项目管理、状态追踪 |
| **Idea Discovery** | 创业想法录入与 Pipeline 管理 |
| **Evaluation** | 五维度评分（技术/商业/市场/团队/创新），雷达图可视化 |
| **Prototypes** | 原型架构追踪、技术可行性评估 |
| **Agent Populations** | 8 种 Agent 模板管理，覆盖人设、经济行为、决策偏好属性 |
| **Simulations** | 模拟场景配置、运行管理、实时监控与结果展示 |
| **Market Validation** | 采用率评分、支付意愿、留存率、情绪分布、转化漏斗 |
| **Business Viability** | 收入/成本预测、盈亏平衡、单位经济学（CAC/LTV/ARPU） |
| **Investment Matching** | 投资人匹配推荐、适配度评分 |
| **Knowledge Graph** | 实体关系图谱可视化 |
| **Reports** | 结构化验证报告生成与历史管理 |
| **Admin** | 用户管理、多角色权限体系 |

### 2.2 核心功能流程

**三步流程**：

**Step 1 — 描述你的想法**
- 结构化表单：产品描述、目标用户、定价策略、竞品参照
- 可选模板（SaaS / Marketplace / Content App / Hardware）
- 一键导入已有 pitch deck 或 lean canvas

**Step 2 — 大规模 Agent 模拟**
- 系统自动生成 **100-300 个角色 Agent**（8 种类型）
- Agent 在虚拟市场环境中自由交互 30-100 轮
- 动态优化技术确保成本可控的同时保证模拟质量
- 实时进度面板展示交互动态

**Step 3 — 多维度分析报告**
- 采用率评分（Adoption Score）
- 市场情绪分布（Sentiment Distribution）
- 转化漏斗（Awareness → Interest → Consideration → Intent → Purchase → Retention）
- 单位经济学（CAC / LTV / ARPU / Break-even）
- 投资人匹配推荐
- 框架分析（Lean Canvas、SWOT 自动填充）
- 关键风险与建议
- 与任意 Agent 追问对话

### 2.3 Agent 体系

**8 种 Agent 类型**：

| Agent 类型 | 典型数量 | 行为特征 |
|-----------|---------|--------|
| Consumer（消费者） | 50-200 | 消费偏好、价格敏感度、口碑传播 |
| Enterprise Buyer（企业客户） | 10-50 | 采购流程、预算评估、供应商对比 |
| Competitor（竞争对手） | 5-15 | 威胁评估、竞品反应策略、价格战 |
| Investor（投资人） | 3-8 | 估值分析、市场规模评估、风险判断 |
| Supplier（供应商） | 3-10 | 合作条件、定价谈判、供应能力 |
| Regulator（监管方） | 2-5 | 合规审查、资质要求、政策风险 |
| Technical Expert（技术专家） | 2-5 | 技术可行性、架构风险、技术债 |
| Mentor（导师） | 1-3 | 战略建议、行业洞察、经验传承 |

每个 Agent 具备完整的**人设档案**（背景、偏好、经济特征、决策逻辑），而非简单的角色标签，确保模拟行为的真实性和多样性。

## 6. 技术优势

BizSim 的技术架构围绕三个核心目标设计：**模拟质量**、**交付速度**、**成本可控**。

### 6.1 大规模 Agent 模拟引擎

- **层级化协调架构**：支持数百个 Agent 并发交互，不是简单的串行调用，而是具备真实市场动态的群体模拟
- **丰富的 Agent 人设体系**：每个 Agent 具备独立的背景、经济特征、决策逻辑和社交行为模式，确保模拟结果的多样性和真实感
- **涌现式分析**：分析结论不是预设的，而是从 Agent 群体行为中自然涌现——采用曲线、口碑传播、竞品反应链都是模拟的结果而非输入

### 6.2 成本与性能优化

核心挑战：数百个 Agent 的多轮交互意味着大量 AI 推理调用。我们通过以下策略实现商业可行的成本结构：

- **分层 LLM 调度**：高价值交互（关键决策、深度讨论）使用强模型，背景行为（日常对话、常规反应）使用轻量模型，在不牺牲模拟质量的前提下大幅降低成本
- **智能缓存与批处理**：相似人设的 Agent 复用推理结果，并行批量调用减少延迟
- **动态规模调整**：根据模拟阶段自动调整活跃 Agent 数量，避免无效计算

| 场景 | Agent 数 | 成本 | 交付时间 |
|------|---------|------|---------|
| Quick Scan | 20 | A$0.5-1 | 数秒 |
| Standard | 100 | A$3-5 | ~10 秒 |
| Deep Dive | 200+ | A$8-15 | ~1 分钟 |
| Enterprise | 500 | A$25-45 | ~2.5 分钟 |

### 6.3 技术壁垒

- **引擎级复杂度**：竞品要从 prompt chain 转型为大规模模拟引擎，需要重写底层架构，这不是简单的功能迭代
- **学术研究基础**：团队具备多 Agent 系统的研究背景，模拟引擎的设计融合了社会模拟和群体智能领域的成熟方法论
- **持续优化空间**：随着模拟数据积累，可以训练更精准的 Agent 行为模型，形成数据飞轮
