# BizSim — 商业计划书

**数百 Agent 驱动的大规模市场模拟 × 创业验证平台**

---

## Executive Summary

BizSim 是一个基于 **大规模多 Agent 市场模拟** 的创业验证 Web 平台。创业者输入产品描述，系统自动生成数十到数百个消费者、企业客户、竞争对手、投资人、供应商、监管方等多角色 Agent，在虚拟市场环境中自由交互、博弈、涌现，在数分钟内完成一场完整的市场推演，生成包含采用曲线、情绪分布、转化漏斗、单位经济学等多维度的商业可行性分析报告。

**核心差异**：

| 维度 | 传统 AI 验证工具 | 固定 Agent 团队（IdeaProof 式） | **BizSim（我们）** |
|------|---------------|--------------------------|-------------------|
| Agent 数量 | 0（单 LLM） | 7-8 个固定角色 | **数十到数百个动态生成** |
| 分析方式 | LLM 问答 | 串行清单分析 | **市场行为模拟涌现** |
| Agent 交互 | 无 | 无 | **自由博弈、口碑传播、竞品反应链** |
| 技术壁垒 | 极低 | 低（prompt chain） | **高（模拟引擎 + 层级化 Agent 协调）** |

**当前状态**：UI 原型已完成。功能原型涵盖 14 个核心模块，验证了信息架构、用户流程和数据模型设计。8 种 Agent 模板的 schema 定义完整，待集成 OASIS 引擎后实现真实模拟。底层模拟引擎基于成熟开源项目改造，技术风险低、迭代速度快。

**目标市场**：澳洲市场。面向独立开发者、CS 毕业生、创业课堂学生、Vibe Coder 等"产品做得快但不知道怎么验证"的群体。

**商业模式**：按次付费（A$29-49/次）+ Pro 订阅（A$79/月）+ 教育许可 + 培训服务。

## 1. 解决什么问题

### 1.1 痛点

AI 辅助开发（Cursor、Windsurf、Bolt 等）让产品开发从"数月"压缩到"数天"，但商业验证仍然停留在传统速度：

| 传统验证方式 | 成本 | 时间 | 问题 |
|------------|------|------|------|
| 投广告测试 | $500-5,000+ | 2-4 周 | 贵，且只能测试点击率 |
| 用户访谈 | $0-500 | 2-4 周 | 慢，且存在社交偏差 |
| 真实发布 | 机会成本巨大 | 3-6 月 | 如果失败代价极高 |
| 咨询服务 | $2,000-20,000 | 4-8 周 | 贵且建议难以验证 |

**结果**：大量创业者要么跳过验证直接投入（90% 失败率），要么因验证成本过高而放弃好想法。在 Vibe Coding 时代，"做一个 App" 变得容易了，但 "知道该不该做" 没有跟上。

### 1.2 解法

用数百 Agent 的大规模市场模拟替代传统市场试错：

```
输入创业想法
   ↓
自动生成 100-300 个多角色 Agent（消费者/企业客户/竞品/投资人/供应商/监管方/专家/导师）
   ↓
Agent 之间自由交互 30-100 轮（讨论/争论/合作/竞争/口碑传播/竞品反应）
   ↓
涌现出群体行为模式（采用曲线、情绪分布、竞品反应链、转化漏斗）
   ↓
生成可行性报告 + 与任意 Agent 深度对话
```

**核心价值**：在投入真金白银之前，先在数字沙盘里"发布"一次你的产品——看到的不是一个 AI 的建议，而是一个 **虚拟市场的反馈**。

## 2. 产品

### 2.1 已完成的功能原型

我们在 Replit 平台上构建了完整的功能原型，涵盖 **14 个核心模块**：

| 模块 | 功能 | 状态 |

| **Overview 仪表盘** | 项目概览、关键指标、活跃项目统计 | ✅ 已实现 |
| **Projects 管理** | 多项目管理、状态追踪 | ✅ 已实现 |
| **Idea Discovery** | 创业想法录入、Pipeline 管理（6 个待评估想法） | ✅ 已实现 |
| **Evaluation** | 五维度评分（技术/商业/市场/团队/创新），雷达图 | ✅ 已实现 |
| **Prototypes** | 原型架构追踪、技术可行性评估 | ✅ 已实现 |
| **Agent Populations** | 8 种 Agent 模板管理（Persona/Economic/Decision 属性） | ✅ 已实现 |
| **Simulations** | 模拟场景配置、运行列表、结果展示（UI 已完成，待集成真实引擎） | ✅ UI 已实现 |
| **Market Validation** | 采用率评分、WTP、留存率、情绪分布、转化漏斗 | ✅ 已实现 |
| **Business Viability** | 收入/成本预测、盈亏平衡、单位经济学（CAC/LTV/ARPU） | ✅ 已实现 |
| **Investment Matching** | 投资人匹配推荐、适配度评分 | ✅ 已实现 |
| **Knowledge Graph** | 实体关系图谱，14 实体、13 关系 | ✅ 已实现 |
| **Reports** | 结构化验证报告生成、历史报告管理 | ✅ 已实现 |
| **Admin** | 用户管理、角色权限（5 种用户角色） | ✅ 已实现 |

**技术栈**：现代 Web 全栈架构（React + TypeScript + PostgreSQL）

### 2.2 核心功能流程

**三步流程**：

**Step 1 — 描述你的想法**
- 结构化表单：产品描述、目标用户、定价策略、竞品参照
- 可选模板（SaaS / Marketplace / Content App / Hardware）
- 一键导入已有 pitch deck 或 lean canvas

**Step 2 — 大规模 Agent 模拟**
- 系统自动生成 **100-300 个角色 Agent**（8 种类型）
- Agent 在虚拟市场环境中自由交互 30-100 轮
- 动态优化技术确保成本可控的同时保证模拟质量
- 实时进度面板展示交互动态

**Step 3 — 多维度分析报告**
- 采用率评分（Adoption Score）
- 市场情绪分布（Sentiment Distribution）
- 转化漏斗（Awareness → Interest → Consideration → Intent → Purchase → Retention）
- 单位经济学（CAC / LTV / ARPU / Break-even）
- 投资人匹配推荐
- 框架分析（Lean Canvas、SWOT 自动填充）
- 关键风险与建议
- 与任意 Agent 追问对话

### 2.3 Agent 体系

**8 种 Agent 类型**（已在原型中实现模板管理）：

| Agent 类型 | 典型数量 | 行为特征 |
|-----------|---------|--------|
| Consumer（消费者） | 50-200 | 消费偏好、价格敏感度、口碑传播 |
| Enterprise Buyer（企业客户） | 10-50 | 采购流程、预算评估、供应商对比 |
| Competitor（竞争对手） | 5-15 | 威胁评估、竞品反应策略、价格战 |
| Investor（投资人） | 3-8 | 估值分析、市场规模评估、风险判断 |
| Supplier（供应商） | 3-10 | 合作条件、定价谈判、供应能力 |
| Regulator（监管方） | 2-5 | 合规审查、资质要求、政策风险 |
| Technical Expert（技术专家） | 2-5 | 技术可行性、架构风险、技术债 |
| Mentor（导师） | 1-3 | 战略建议、行业洞察、经验传承 |

**规模化技术保障**：通过动态分层调度和智能缓存等优化手段，在数百 Agent 的大规模模拟场景下实现 **成本可控（A$3-49/次）** 和 **速度优化（分钟级完成）**，兼顾模拟质量与商业可行性。

### 2.4 与竞品的本质差异

| 维度 | ValidatorAI | IdeaProof | **BizSim** |
|------|------------|-----------|------------|
| 分析方式 | 单 LLM 问答 | 7-8 固定角色串行分析 | **数百 Agent 市场模拟涌现** |
| Agent 交互 | 无 | 无（串行执行） | **自由博弈、涌现行为** |
| 消费者视角 | AI 代替估计 | 分析师代替评估 | **真正的消费者群体模拟** |
| 技术壁垒 | 极低 | 低（易复制） | **高（大规模模拟引擎）** |
| 本地化 | 美国 | 无 | **澳洲市场数据** |
| 价格 | 免费（基础） | 未公开 | **A$29-49/次** |
| 输出深度 | 评分 + 建议 | 清单式报告 | **市场动态 + 涌现洞察 + 框架分析** |

## 6. 技术

### 6.1 技术基础

基于成熟开源项目改造，技术起点高、风险低：

- **模拟引擎**：基于 GitHub 上 41k+ Stars 的群体智能框架改造，已被学术界和工业界广泛验证
- **Agent 协调**：采用经过百万级 Agent 验证的社会模拟架构，天然支持大规模并发
- **全流程管线**：输入想法 → 知识图谱 → Agent 生成 → 模拟执行 → 报告生成 → 深度互动

### 6.2 性能与成本

| 场景 | Agent 数 | 成本 | 时间 |
|------|---------|------|------|
| Quick Scan | 20 | A$0.5-1 | 数秒 |
| Standard | 100 | A$3-5 | ~10 秒 |
| Deep Dive | 200+ | A$8-15 | ~1 分钟 |
| Enterprise | 500 | A$25-45 | ~2.5 分钟 |

通过动态分层调度、智能缓存、批处理等优化策略，在保证模拟质量的同时实现 **分钟级交付** 和 **78%+ 毛利率**。

### 6.3 开发路线图

| 阶段 | 任务 | 交付物 |
|------|------|-------|
| **Week 1-2** | 模拟引擎改造 + Agent 人设体系 | 核心引擎就绪 |

| **Week 5** | Web 前端 + 支付集成 | 可用产品 |
| **Week 6** | 测试 + 部署 + 首批案例 | **MVP 上线** |

## 8. 我们的优势

1. **技术差异化**：数百 Agent 的大规模市场模拟，是比"LLM 问答"和"固定 Agent 团队"**本质上更丰富** 的验证方式。竞品复制难度高——从 prompt chain 转型为模拟引擎需要重写底层架构
2. **原型已验证产品设计**：Replit 功能原型涵盖 14 个模块、8 种 Agent 模板的完整数据模型定义——信息架构、用户流程、schema 设计均已验证
3. **开源基础**：站在 41k+ Stars 的成熟框架肩膀上，6 周可达 MVP，不是从零开始
4. **高校渠道**：天然的低成本用户获取 + 案例积累 + 培训服务收入
5. **双轮驱动**：产品收入（SaaS）+ 服务收入（培训工作坊），降低早期现金流风险
6. **本地化机会**：澳洲市场的 AI 创业验证工具完全空白
7. **社会价值**：降低学生和新创业者的试错成本，推动 Vibe Coding 和一人公司趋势
