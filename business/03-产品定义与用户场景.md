# 03 - 产品定义与用户场景

## 1. 产品概述

### 1.1 产品名称（暂定）

**BizSim** — Business Simulation for Idea Validation

备选：LaunchSim / IdeaSandbox / PreLaunch / MarketMirror

### 1.2 一句话描述

> 用多 Agent 模拟帮创业者在发布前验证 App/数字产品的商业可行性。

### 1.3 产品形态

**Web App**（MVP 阶段），后期可考虑移动端适配。

- 用户通过浏览器访问
- 输入产品描述和参数
- 系统运行 Agent 模拟
- 生成可视化报告
- 支持与模拟角色深度对话

## 2. 核心用户场景

### 场景一：App 创业者的市场验证

**用户**：Sarah，25 岁，UQ 计算机科学毕业生，墨尔本

**背景**：Sarah 用 Cursor + Claude 在两周内做了一个"宠物寄养匹配平台"App 的 MVP。她不确定这个产品在澳洲市场是否有需求，该定价多少，以及最大的风险是什么。

**传统路径**：
1. 在 Facebook 上投 $500 广告看点击率 → 2 周
2. 朋友圈问 20 个人的意见 → 高度偏差
3. 上线 App Store 看下载量 → 3-6 周 + $99 年费

**用我们的产品**：
1. Sarah 打开 BizSim，输入产品描述：
   - "一个连接宠物主人与当地宠物看护者的双边平台"
   - 目标市场：澳洲主要城市
   - 定价模型：平台抽佣 15%
   - 竞品参照：Mad Paws、Pawshake

2. 系统自动生成 Agent 群体：
   - 50-200 位 **潜在消费者 Agent**（不同年龄/收入/养宠类型/城市/消费偏好/决策风格）
   - 20-50 位 **企业客户 Agent**（不同规模/预算/采购流程/决策链）
   - 5-10 位 **竞品 Agent**（模拟 Mad Paws、Rover 等的反应策略）
   - 5-10 位 **供应商 Agent**（宠物看护服务提供者、资源供应方）
   - 3-5 位 **天使投资人 Agent**（按不同基金偏好配置）
   - 2-3 位 **监管方 Agent**（模拟动物福利法规、平台合规要求）
   - 2-3 位 **技术专家 Agent**（评估技术可行性、架构风险）
   - 1-2 位 **行业导师 Agent**（提供宏观市场视角和战略建议）

   **总计约 100-300 个 Agent 构成完整的虚拟市场生态。**

3. 运行 30-100 轮模拟：
   - 消费者 Agent 之间讨论"会不会用这个产品"，自发形成口碑传播
   - 企业客户 Agent 评估"这个方案是否满足我们的需求"
   - 竞品 Agent 评估"是否需要调整策略应对"
   - 供应商 Agent 讨论"合作条件和定价"
   - 投资人 Agent 讨论"值不值得投，估值多少"
   - 监管方 Agent 审查"是否合规，需要什么牌照"
   - **Agent 之间自由交互，涌现出市场行为模式**

4. 生成报告：
   - 商业可行性评分
   - 关键风险清单
   - 用户画像聚类
   - 定价建议
   - 竞争策略建议

5. Sarah 可以追问任意 Agent："你说不会用这个产品，是因为什么？"

**时间**：1-2 小时（含等待模拟运行）
**成本**：A$29-49

### 场景二：侧项目优先级排序

**用户**：Mike，35 岁，独立开发者，悉尼

**背景**：Mike 有三个 App 创意在脑海中打转：
- A: 本地美食推荐小程序
- B: 个人碳足迹追踪 App
- C: 自由职业者发票管理工具

他不知道该先做哪个。

**用我们的产品**：
- 分别对三个想法运行快速模拟（精简模式，10-15 轮）
- 对比三份报告的可行性评分、市场空间、竞争强度
- 选择最优方向全力投入

### 场景三：创业课堂教学工具

**用户**：Prof. Chen，某大学创业学讲师

**背景**：每学期有 60+ 学生提交创业计划作业。手动给每个团队提供个性化反馈非常耗时。

**用我们的产品**：
- 学生团队将创业计划输入 BizSim
- 系统自动运行模拟并生成报告
- 报告作为课堂讨论和迭代的基础
- 教师可以看到所有团队的模拟结果摘要

**价值**：
- 节省教师时间
- 学生获得多角色反馈而非单一教师视角
- 可重复运行（修改方案后重新模拟）

## 4. Agent 角色设计

### 4.1 核心角色类型

BizSim 通过大规模 Agent 群体模拟真实市场生态。与 IdeaProof 等"7-8 个固定分析师"的方案不同，我们动态生成 **数十到数百个** 各类 Agent，让它们在虚拟市场中自由交互，产生涌现行为。

| 角色类型 | 典型数量 | 来源 | 行为特征 |
|---------|---------|------|---------|
| **消费者（Consumer）** | 50-200 | 基于产品描述和市场数据动态生成 | 不同人口统计、收入水平、消费偏好、决策风格、价格敏感度 |
| **企业客户（Enterprise Buyer）** | 10-50 | 基于 B2B 场景自动配置 | 不同企业规模、预算、采购流程、技术成熟度 |
| **竞争对手（Competitor）** | 5-15 | 基于竞品输入 + 自动搜索生成 | 评估威胁程度、制定应对策略、模拟价格战/功能竞赛 |
| **投资人（Investor）** | 3-8 | 预配置不同基金偏好和投资标准 | 评估可投资性、市场规模、团队风险、估值合理性 |
| **供应商（Supplier）** | 3-10 | 基于供应链分析生成 | 评估合作条件、定价谈判、供应能力 |
| **监管方（Regulator）** | 2-5 | 基于行业法规配置 | 合规审查、资质要求、政策风险提示 |
| **技术专家（Technical Expert）** | 2-5 | 预配置不同技术领域 | 技术可行性、架构风险、技术债评估 |
| **导师（Mentor）** | 1-3 | 预配置行业资深人士 | 宏观市场视角、战略建议、经验传承 |

> **关键差异**：IdeaProof 有 7-8 个分析师串行输出报告；我们有 **数百个市场参与者** 在虚拟环境中自由博弈。前者给你"分析"，后者给你"市场反馈"。

### 4.2 大规模 Agent 模拟能力

BizSim 支持 **数百个 Agent 同时交互** 的大规模市场模拟，通过动态分层调度和智能优化技术，在保证模拟质量的同时实现成本可控和分钟级交付。

**关键能力**：
- 数百 Agent 并发交互，产生真实的市场涌现行为
- 智能调度确保关键决策者（投资人、竞品）获得高精度推理
- 大量消费者 Agent 产生统计可信的群体行为数据
- 成本控制在 A$3-49/次，运行时间控制在分钟级

### 4.3 Agent 人设生成

系统自动为每个 Agent 生成差异化的多维人设，确保模拟的多样性和真实性。每个 Agent 包含三大属性维度：

| 属性维度 | 包含字段 | 用途 |
|---------|---------|------|
| **Persona 属性** | 年龄、职业、收入、城市、消费习惯 | 基本画像 |
| **Economic 属性** | 支付意愿、预算范围、价格敏感度 | 经济行为 |
| **Decision 属性** | 决策风格、风险偏好、品牌忠诚度、技术接受度 | 决策特征 |

> 功能原型的 Agent Populations 模块已实现 8 种 Agent 模板的可视化管理，支持灵活配置。

### 4.4 商业分析框架嵌入

在 Agent 交互和报告生成中，融入经典商业分析模型：

| 框架 | 融入方式 | 报告体现 |
|------|---------|---------|
| **Lean Canvas** | Agent 讨论结果映射到 Canvas 的 9 个格子 | 自动填充的 Lean Canvas |
| **Porter's Five Forces** | 竞品 Agent 的行为体现五力模型 | 竞争强度雷达图 |
| **TAM/SAM/SOM** | 消费者 Agent 的覆盖范围推算市场 | 市场规模漏斗图 |
| **SWOT** | 汇总所有 Agent 视角的优势/劣势/机会/威胁 | SWOT 矩阵 |
| **Jobs-to-be-Done** | 消费者 Agent 表达的需求映射到 JTBD 框架 | 用户需求优先级 |
| **PMF 信号检测** | 消费者 Agent 的使用意愿、付费意愿、推荐意愿 | PMF 评分 |

## 5. 用户旅程

```
[发现阶段]
  │ 从高校推荐 / 搜索引擎 / 社群推广到达
  ↓
[注册/试用]
  │ Google 登录 → 免费模拟 1 次（精简模式）
  ↓
[输入想法]
  │ 引导式表单：产品描述 → 目标用户 → 定价 → 竞品
  │ 可选择模板快速开始（SaaS / App / Marketplace）
  ↓
[选择模拟深度]
  │ Quick Scan（免费，5-10 Agent，10 轮）
  │ Standard（A$29，15-20 Agent，30 轮）
  │ Deep Dive（A$49，30+ Agent，40 轮 + 框架分析）
  ↓
[等待模拟]
  │ 实时进度条 + Agent 交互片段预览
  │ 预计 5-15 分钟
  ↓
[查看报告]
  │ 可行性评分 + 多维度分析 + 风险清单 + 建议
  │ 可展开每个 Agent 的发言记录
  ↓
[深度交互]
  │ 点击任意 Agent → 追问式对话
  │ "你说不会用这个产品，是因为价格太高还是功能不够？"
  ↓
[导出/迭代]
  │ 下载 PDF 报告
  │ 修改参数重新模拟
  │ 对比多个方案
```

## 6. Demo 案例设计（首批 1-2 个）

### 案例一：健身社交 App

**场景**：一个 App 创意——帮助健身爱好者找到同城训练伙伴，澳洲市场。

**输入参数**：
- 产品：Gym Buddy matching App
- 目标市场：18-35 岁健身爱好者，Sydney/Melbourne
- 商业模式：Freemium + Premium 月订阅 A$9.99
- 竞品：Strava（运动追踪）、Meetup（活动组织）

**预期模拟产出**：
- 消费者 Agent 反映"已经有微信群了，不需要新 App"
- 部分 Agent 表示"健身房自带社交，不需要线上匹配"
- 投资人 Agent 指出"双边平台冷启动问题严重"
- 分析师 Agent 提供"澳洲健身房渗透率数据"

### 案例二：二手教科书交易平台

**场景**：大学生之间的二手教科书交易 App。

**输入参数**：
- 产品：Campus Book Exchange
- 目标市场：澳洲大学生
- 商业模式：交易佣金 10% + 精选推荐
- 竞品：Gumtree、Facebook Marketplace、大学内部 BBS

**预期模拟产出**：
- 学生 Agent 反映"买二手书已经在 Facebook 群里免费交易"
- 但也有 Agent 表达"希望有信任评价机制"
- 投资人评估"市场天花板低，但可以作为校园入口"
- 揭示关键洞察：痛点不在"找到书"，而在"确认版本和质量"

## 7. 非功能需求

| 维度 | 要求 | 原因 |
|------|------|------|
| 响应时间 | 模拟完成 < 15 分钟 | 用户耐心有限 |
| 成本控制 | 单次模拟 LLM 成本 < A$5 | 保证毛利 |
| 语言 | 英文为主，支持中文报告 | 澳洲市场为英文 |
| 安全 | 用户商业想法严格保密 | 信任基础 |
| 可用性 | 非技术人员可独立使用 | 目标用户不一定懂技术 |
