# SimuVerse Platform — 前端开发方案

> 编制日期：2026-03-25

## 技术栈

| 层面 | 选型 | 说明 |
|------|------|------|
| 框架 | React 18 + TypeScript | 沿用 Replit UI 原型的技术选型 |
| 构建 | Vite 5 | 快速 HMR，去掉 Replit 专属插件 |
| 样式 | Tailwind CSS 3 + shadcn/ui | 沿用原型的 Radix UI 组件体系 |
| 路由 | wouter | 轻量 SPA 路由 |
| 图表 | Recharts | 折线图、柱状图、雷达图 |
| 图标 | lucide-react | 一致的图标风格 |
| 数据 | Mock data（内存）| 无后端依赖，前端独立运行。Replit 原型的后端也是预置数据 + `Math.random()`，无真实模拟 |

## 页面清单（15 页）

### 原有页面（参考 Replit UI 原型的信息架构，使用 mock data 重写）
1. **Overview** — KPI 仪表盘、趋势图、活动流
2. **Projects** — 项目卡片列表、状态管理
3. **Idea Discovery** — 创意提交与浏览
4. **Evaluation** — AI 评分雷达图、评审列表
5. **Prototypes** — 原型架构规划
6. **Agent Populations** — 8类 Agent 模板管理
7. **Simulations** — 模拟场景配置与运行列表
8. **Market Validation** — 市场验证指标与评分
9. **Business Viability** — 财务可行性分析
10. **Investment Matching** — 投资人匹配
11. **Knowledge Graph** — 知识图谱可视化
12. **Reports** — 报告生成与导出
13. **Admin** — 平台管理

### 新增页面（核心差异化）
14. **Simulation Live View** — 实时模拟过程可视化
    - Agent 交互时间线（对话气泡 + 情感标签）
    - 实时进度条（轮次 / 总轮次）
    - 右侧指标面板（采用率、市场情绪、Agent 分布）
    - Agent 类型头像 + 颜色编码
    - 参考 `simulation-live.html` mockup 的布局
    - **数据模型说明**：OASIS 引擎中 Agent 间不直接通信，所有交互通过平台 SQLite DB 中转（帖子→推荐算法→其他 Agent 可见），前端展示"对话"时实际是从 trace 表提取的帖子/评论/投票序列，需做格式转换（详见技术方案 §1.5.2）

15. **404 Not Found**
