# 10万级 Agent 模拟成本估算 & LLM API 价格参考

## 一、模拟规模假设

| 参数 | 数值 |
|---|---|
| Agent 数量 | 100,000 |
| 平均输入 token / 次调用 | 2,000 |
| 平均输出 token / 次调用 | 200 |
| Timestep 数 | 10 |
| 每轮激活比例 | 30% |

## 二、单次任务总 Token 消耗

$$
\text{总调用次数} = 100{,}000 \times 0.3 \times 10 = 300{,}000 \text{ 次}
$$

| 项目 | 计算 | 结果 |
|---|---|---|
| 总调用次数 | 10万 × 30% × 10 步 | **30 万次** |
| 总输入 token | 30万 × 2,000 | **6 亿 token** |
| 总输出 token | 30万 × 200 | **6,000 万 token** |

## 三、云端 API 成本估算

### 方案 A：Claude Sonnet 4.6

> 输入 $3 / 百万 token　·　输出 $15 / 百万 token

| 项目 | 计算 | 费用 |
|---|---|---|
| 输入成本 | 600M × $3 / 1M | $1,800 |
| 输出成本 | 60M × $15 / 1M | $900 |
| **合计** | | **~$2,700（约 ¥19,500）** |

### 方案 B：DeepSeek V3 API（最具性价比的云端选择）

> 输入 $0.27 / 百万 token（缓存命中 $0.07）　·　输出 $1.10 / 百万 token

| 项目 | 计算 | 费用 |
|---|---|---|
| 输入成本 | 600M × $0.27 / 1M | $162 |
| 输出成本 | 60M × $1.10 / 1M | $66 |
| **合计** | | **~$228（约 ¥1,650）** |

## 四、本地部署方案（最便宜，前提是有 GPU）

> 本地成本结构：固定 GPU 硬件/租金 + 可忽略的电费，无 per-token 计费。

| 配置 | 时长 | 估算成本 |
|---|---|---|
| 单卡 H100 | 8–10 小时 | ~$20–30 |
| 4卡 H100 并行 | 2–3 小时 | ~$25–35 |
| A100（$1.2/小时） | 较慢 | ~$15–25 |
| 单卡 3090/4090 + Llama 3.1 8B / Qwen2.5 7B | 视任务 | **~$5–10** |

> ⚠️ 小模型（8B 级）成本极低，但 agent 行为真实度会有所下降。

## 六、选型建议

| 场景 | 推荐模型 |
|---|---|
| Agent / 工具调用 | GPT-5.4（可靠性）或 Claude Sonnet 4.6（长上下文），预算有限选 Gemini 2.5 Pro |
| 代码生成 | Claude Sonnet 4.6，最难任务用 Opus 4.6 |
| 高并发简单任务（分类 / 路由 / 提取） | Gemini 2.5 Flash-Lite（100 万条消息约 $17.5/月） |
| 大规模 Agent 模拟，极致省钱 | DeepSeek V3 API 或本地部署小模型 |
